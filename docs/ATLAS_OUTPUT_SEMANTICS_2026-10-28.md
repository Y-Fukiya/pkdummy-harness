# カード表示と生成成果物への評価情報の引き継ぎ

[パラメータ画面](https://y-fukiya.github.io/pkdummy-harness/parameters/) / [評価・用量・選択方針](https://y-fukiya.github.io/pkdummy-harness/fixture-governance/)

## 表示する値の意味

カタログの半減期は「t½参照・検証用」とし、CL/Vから計算したモデル半減期を別に併記します。参照値には文献値だけでなく既存fixtureの導出値も含まれるため、すべてを独立した文献観測値とは呼びません。

小さな正のCLは有効数字3桁で表示します。モタビズマブ-YTEのCLは `0.00229 L/h`、CDA1は `0.00588 L/h`、モタビズマブは `0.0102 L/h`、テフィバズマブは `0.0120 L/h` と表示されます。保存された数値や単位を丸め直していません。

全37剤についての総括は「臨床モデルとして未承認」とします。個別の評価状態である「保留」「未評価」と区別します。アブシキシマブの保留追加後は、7剤保留・30剤未評価です。対称1.5倍チェックの保留候補は引き続き10剤です。

作用機序の引用確認は「作用機序: 引用確認済み」と表示します。パラメータ台帳の照合状態は「出典記録一致」とし、引用に対応する記録や導出入力が照合されているという意味に限定します。臨床モデル評価の承認ではありません。

Dose/CL等から作られた整合性チェック用AUCの画面表示は有効数字3桁とします。正本の計算値は保持します。

## アブシキシマブの保留

[2013年のFDA ReoProラベル](https://www.accessdata.fda.gov/drugsatfda_docs/label/2013/103575s5126lbl.pdf)の印刷p.2、Clinical Pharmacology / Pharmacokineticsには、遊離血漿中濃度の初期半減期10分未満、次相約30分、および血小板結合薬物が15日以上残ることが記載されています。速い血漿濃度低下は血小板GPIIb/IIIaへの結合と関係づけられています。過去の承認ラベルをPKの記述確認に用いており、現在の用量案内として利用していません。

採用CL 183 mL/minの[原著抄録、PMID 11907493](https://pubmed.ncbi.nlm.nih.gov/11907493/)は健康成人の定常状態値を報告します。一方、採用Vの[既存source_6、Wiley学会抄録](https://ascpt.onlinelibrary.wiley.com/doi/abs/10.1016/j.clpt.2003.11.342)は安定狭心症52例の試験で、Vss 1.44 L/kgと遊離薬物の三指数減衰を記載します。

遊離血漿薬物と血小板結合薬物を固定線形1-compartmentモデルでは分離して表現できず、CL・V・短い血漿半減期が異なる試験・集団・要約に由来するため、`clinical_hold` としました。特定の標的介在性薬物動態モデルが検証済み、あるいは線形近似が数学的に不可能、とまでは主張しません。数値の再較正は行っていません。

### Vの確認履歴

2026-10-02監査の「V未確認」は当時の記録として残しました。2026-10-28には、同じ出版社URLの検索索引に収録された学会抄録で1.44 L/kgを再確認しました。出版社URLの直接取得はHTTP 403だったため、全文を直接取得・確認したとは扱いません。

この確認経路と日付を現在のVの由来記録へ追加し、詳細画面の過去監査欄の隣に表示します。学会抄録レベルである制約と、モデルの保留は維持します。

## EX・ADPC・マニフェスト

生成処理の実行結果が `OK` でも、臨床モデルとして使用可能という意味にはしません。各生成段階のマニフェストに、技術的な実行状態と別の `fixture_context` を保存します。

| 項目 | 意味 |
| --- | --- |
| `clinical_use: not_approved` | 臨床モデルとして未承認 |
| `simulation_validity` | 保留／未評価と、その理由 |
| `dose_purpose: computational_stress_test` | 計算用投与設定 |
| `clinical_dose_verified: false` | 常用量として未確認 |
| `half_life_check` | 1.5倍チェックの候補判定と、独立した照合かどうか |
| `context_source` | 文脈を取得したspec・PK・targetsの入力経路 |

CSVにも `CLINICAL_ASSESSMENT`、`CLINICAL_USE`、`HOLD_REASONS`、`DOSE_PURPOSE`、`CLINICAL_DOSE_VERIFIED`、`HOLD_CANDIDATE` を引き継ぎます。実行用量は従来の用量列に保持します。濃度・時刻・用量の数値列は変更しません。

specが分かる境界で、明示された正本、または同じディレクトリの正本から文脈を取得します。正本がない単独specでは未評価とし、臨床承認を推定しません。pkだけから保留が分かる場合も、その保留を失わせません。後続処理は渡された文脈を照合し、CSVとマニフェストの承認状態が食い違う入力を拒否します。

旧生成物はこの変更によって再認証されません。新しい情報を含む成果物が必要な場合は、更新後の処理で再生成してください。

同梱の最小3例は、従来のCSV列・行・値を保持して評価列を追加し、analysis出力を再生成しました。入力に正本評価の由来がないため、未評価・未承認の既定値としています。例の照合検査でも文脈情報の差分を検出します。
